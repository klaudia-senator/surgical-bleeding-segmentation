# Published aggregate results

`segmentation_cv.csv` contains only aggregate values reported in the associated 2026 paper.
It contains no image names, source paths, annotations, patient information, or model weights.

The standard-deviation columns use the sample definition (`ddof=1`) across five folds.
These values document the published experiments; they are not regenerated by the public
repository because the private/internal datasets are not distributed.

Please cite the associated paper when using or discussing these results:

K. Senator, D. Krawczyk, and Z. Nawrat, “Deep Learning-Based Blood Segmentation and
Temporal Characterization for the Robin Heart Surgical Robot,” *Surgeries*, 2026.
https://doi.org/10.3390/surgeries7020070
